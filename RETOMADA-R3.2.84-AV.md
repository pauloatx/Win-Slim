[Evidências locais](logs/ci-hosted-implementation-20261029/), inclusive `stabilized-evidence/SHA256.json`. Isso preserva o executável dos aceites anteriores sem atribuir aceite físico ao build de CI.

**Falta para executar hospedada:** esta pasta não tem `.git`/remoto/branch; `gh` ausente, nenhuma credencial não interativa disponível e integração GitHub não confirmada conectada. A UI aponta para `pauloatx/Win-Slim`, existente na API pública, mas isso não associa o checkout nem concede escrita. Nenhum push/dispatch; **URL/ID hospedado inexistentes**. Próximo item elegível da frente CI: disponibilizar checkout autenticado do repositório correto, incorporar a candidata preservando os bytes, executar o workflow e conservar URL/SHA/run_id/tentativa/artefatos reais. Somente sucesso hospedado integral permite registrar CI aprovada. Na fila técnica independente, licença/ABI e leitor AMD restrito continuam elegíveis quando retomados; multimonitor físico exige ambiente apropriado e permanece não demonstrado.
